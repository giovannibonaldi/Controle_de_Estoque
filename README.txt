ESTOQUE AZUL — CONTROLE INTELIGENTE

COMO ABRIR
1. Extraia todos os arquivos do ZIP para uma pasta.
2. Abra o arquivo index.html no Google Chrome, Microsoft Edge ou Firefox.
3. Não é necessário instalar programas nem executar servidor.

ARQUIVOS
- index.html: estrutura do site.
- styles.css: layout, cores, responsividade e impressão.
- script.js: cadastros, cálculos, filtros, gráficos e armazenamento.

RECURSOS PRINCIPAIS
- Cadastro, edição e exclusão de produtos.
- Registro de entradas, saídas, perdas e ajustes.
- Cálculo de dias corridos desde a compra e dias até o vencimento.
- Alertas de estoque mínimo, saldo zerado, vencimentos e produtos vencidos.
- Gráficos de movimentação, categoria, status, vencimentos e vendas diárias.
- Relatórios de receita, custo, lucro, margem, giro e ranking de produtos.
- Exportação de tabelas em CSV, backup completo em JSON e restauração.
- Dados salvos no próprio navegador (localStorage).

OBSERVAÇÃO
O site inicia com dados demonstrativos. Você pode editá-los ou apagá-los.
Para trabalhar em outro computador, exporte o Backup e use Restaurar no novo navegador.
